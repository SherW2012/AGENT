# 我的美食地图 🗺️🍜

一个**纯个人**的美食收藏地图 APP：地图、评分、种类、排行榜全都有，
所有店铺都由自己添加，没有任何外部推荐和算法干扰。

## 功能

- **地图**：高德底图，点击地图任意位置即可添加一家店，标记按种类显示不同表情和颜色
- **评分**：1~5 星打分，支持人均价格和备注（推荐菜 / 踩雷提醒）
- **种类**：内置火锅、烧烤、面食、中餐、日料、西餐、甜点、饮品、小吃等，也支持自定义种类
- **列表**：按最近更新排序，支持关键词搜索、按种类 / 评分筛选，点卡片飞到地图对应位置
- **排行榜**：按评分排名（🥇🥈🥉），可结合种类筛选看"火锅榜""面馆榜"
- **统计**：总店数、平均分、五星店数量、各种类分布
- **定位**：一键回到当前位置（已做 WGS-84 → GCJ-02 纠偏，与高德底图对齐）
- **导出 / 导入**：一键备份为 JSON 文件，换设备也能带走数据

## 使用方式

无需安装、无需构建，直接用浏览器打开：

```
food-map-app/index.html
```

双击文件即可（推荐 Chrome / Edge / Safari）。也可以起个本地服务：

```bash
cd food-map-app
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 需要联网加载地图瓦片和 Leaflet 库，数据本身全部保存在本机浏览器
> localStorage 中，不会上传到任何服务器。

## 数据格式

```json
{
  "app": "food-map",
  "version": 1,
  "spots": [
    {
      "id": "…",
      "name": "老王牛肉面",
      "category": "面食",
      "rating": 5,

      "notes": "牛肉给得足，中午排队",
      "lat": 39.909,
      "lng": 116.397,
      "createdAt": 1720000000000,
      "updatedAt": 1720000000000
    }
  ]
}
```
