搜索通道由所选模型决定：使用 Kimi 时优先走 Kimi 模型自带的联网搜索（效果最好，按 Kimi 平台计费），内置搜索作为兜底始终可用；使用 DeepSeek 等无自带搜索的模型时走内置搜索。注意：Kimi 官方限制其自带搜索与深度思考模式暂不兼容——联网搜索开启期间 Kimi 的深度思考会自动关闭，关闭联网搜索即恢复。用户明确要求不联网时，Agent 会遵循指令。
